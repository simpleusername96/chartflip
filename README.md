# CHARTFLIP · 차트플립

[English](README.en.md)

![차트플립 플레이 화면](media/preview.gif)

개미 직장인이 사무실 의자를 타고 차트 위를 미끄러져 퇴근하는 브라우저 게임입니다.

바닥에서 **뒤집으면** 앞의 오르막이 내리막이 됩니다. 코인을 모아 **부스트**로 달리고, 금메달 기록에 도전하세요. 쌍바닥, 데드캣 바운스, 숏스퀴즈, 버블… 15개 코스는 모두 게임을 위해 만든 가상 차트입니다.

## 플레이

**[▶ 브라우저에서 바로 플레이](https://simpleusername96.github.io/chartflip/)**

내려받아서 `index.html`을 열어도 됩니다. 설치도 인터넷 연결도 필요 없습니다.

| | 키보드 | 터치 |
|---|---|---|
| 뒤집기 | Space | 화면 탭 |
| 부스트 | X 누르고 있기 | 오른쪽 아래 버튼 누르고 있기 |
